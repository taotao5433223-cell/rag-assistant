# 02. Transformer 与 GPT 架构

> 对应章节：第 1 章 1.4–1.8

## 一、Transformer 架构介绍

大部分现代 LLM 基于 **Transformer 架构**，这是一种深度神经网络架构，由谷歌在 2017 年论文《Attention Is All You Need》中首次提出。Transformer 最初为机器翻译任务（如英译德/法）开发。

### 1.1 原始 Transformer 的两大子模块

Transformer 由两部分组成：

- **编码器（encoder）**：处理输入文本，将其编码为一系列数值表示或向量，捕捉上下文信息。
- **解码器（decoder）**：接收编码向量，据此生成输出文本。

以翻译为例：编码器把源语言文本编码成向量，解码器把向量解码成目标语言文本。两者都由多层组成，这些层通过 **自注意力机制（self-attention mechanism）** 连接。

### 1.2 自注意力机制的作用

自注意力机制是 Transformer 和 LLM 的一大关键组件，它允许模型衡量序列中不同单词或词元之间的相对重要性。这使得模型能捕捉长距离依赖和上下文关系，从而生成连贯且上下文相关的输出。由于其复杂性，本书第 3 章会专门讲解并逐步实现。

### 1.3 Transformer 的变体：BERT 与 GPT

为适应不同下游任务，Transformer 衍生出多种变体：

- **BERT（Bidirectional Encoder Representations from Transformer）**：基于编码器模块。训练方法是 **掩码预测（masked word prediction）**——预测句子中被掩码的词。擅长文本分类（如情感预测、文档分类）。X（前 Twitter）检测有害内容就使用 BERT。
- **GPT（Generative Pretrained Transformer）**：侧重于解码器部分。主要用于生成任务（机器翻译、文本摘要、小说写作、代码编写）。

```
原始 Transformer
├── 编码器 → BERT 类（掩码预测，擅长分类）
└── 解码器 → GPT 类（下一词预测，擅长生成）
```

### 1.4 零样本与少样本学习

GPT 主要被设计和训练用于 **文本补全（text completion）** 任务，但表现出色的可扩展性：

- **零样本学习（zero-shot learning）**：在没有任何特定示例的情况下，泛化到从未见过的任务。
- **少样本学习（few-shot learning）**：从用户提供的少量示例中学习并执行任务。

GPT 模型能根据输入执行各种任务，而无须重新训练、微调或针对特定任务更改模型架构。

## 二、利用大型数据集

主流 GPT、BERT 等模型使用的训练数据集涵盖多样而全面的文本语料库，包含数十亿词汇，涉及广泛主题。

### 2.1 GPT-3 的预训练数据集（示例）

GPT-3 是第一代 ChatGPT 的基础模型。其训练数据集"训练数据中的比例"总计 100%（按舍入误差调整）。"词元数量"总计 4990 亿，但模型实际只在 3000 亿个词元上训练（作者未说明原因）。

以 CommonCrawl 数据集为例：4100 亿词元，约 570 GB 存储空间。Meta 的 Llama 扩展了数据源，包括 Arxiv 研究论文（92 GB）、StackExchange 代码问答（78 GB）。

### 2.2 词元（token）的概念

词元是模型读取文本的基本单位。数据集中的词元数量大致等同于文本中的单词和标点符号数量。第 2 章会详细介绍分词——即将文本转换为词元的过程。

### 2.3 预训练成本

预训练 LLM 需要大量资源，成本极其高昂：

- GPT-3 预训练云计算费用估计 **460 万美元**。
- Llama 2 70B 在 A100 GPU 上训练 184,320 GPU 小时，约 **69 万美元**（184320÷8×30 美元/小时）。

好消息是许多预训练 LLM 是开源的，可用相对较小的数据集微调特定任务，减少计算资源并提升性能。本书实现预训练代码后，会学习复用公开可用权重，跳过昂贵预训练。

## 三、深入剖析 GPT 架构

### 3.1 GPT 的起源

GPT 最初由 OpenAI 的 Radford 等人在论文《Improving Language Understanding by Generative Pre-Training》中提出。GPT-3 是其扩展版（更多参数、更大数据集）。ChatGPT 原始模型是用 OpenAI InstructGPT 论文方法在大型指令数据集上微调 GPT-3 而成。

### 3.2 下一词预测与自监督学习

GPT 模型仅在相对简单的下一词预测任务上预训练，却能有如此强大而全面的能力，令人惊叹。下一词预测采用 **自监督学习**：

- 不需要专门收集标签。
- 利用数据本身的结构——句子/文档中的下一个词即标签。
- 任务允许"动态"创建标签，因此可利用大量无标注文本训练。

### 3.3 GPT 的纯解码器架构

与原始 Transformer（编码器+解码器）相比，GPT 通用架构更简洁：

- **本质上只包含解码器部分**，不含编码器。
- 由于通过逐词预测生成文本，GPT 是 **自回归模型（autoregressive model）**——将之前输出作为未来预测的输入。
- 每个新词根据它之前的序列选择，提高最终文本的一致性。
- 从左到右单向处理，非常适合文本生成和下一词预测任务。

```
原始 Transformer（6 层编码器 + 6 层解码器）
            ↓ 简化
GPT 架构（仅解码器，单向从左到右）
            ↓ 扩展
GPT-3（96 层 Transformer，1750 亿参数）
```

### 3.4 涌现能力（emergence）

GPT 模型能完成未经明确训练的任务，这种能力称为 **涌现**。例如，GPT 主要在下一词预测任务上训练，却能执行翻译任务——这种能力起初让研究人员颇为意外。涌现来自模型广泛接触大量多语言数据和各种上下文的自然结果，而非训练期间被明确教授。

## 五、关键概念辨析

| 概念 | 要点 |
|---|---|
| 编码器 vs 解码器 | 编码器处理输入生成表示；解码器接收表示生成输出 |
| BERT vs GPT | BERT 用编码器做掩码预测擅长分类；GPT 用解码器做下一词预测擅长生成 |
| 自回归 | 将之前输出作为未来预测输入，GPT 逐词生成 |
| 涌现 | 未经明确训练却展现的能力，源于大规模多语言数据接触 |
| 词元 | 模型读取文本的基本单位，大致等同于单词+标点 |
| 权重共享 | 原始 GPT-2 把词元嵌入层当输出层复用，减少参数量（第 4 章详述） |

## 六、本篇要点

- Transformer 由编码器和解码器组成；BERT 用编码器做掩码预测擅长分类，GPT 用解码器做下一词预测擅长生成。
- GPT 是纯解码器、自回归模型，从左到右单向处理。
- LLM 的强大能力来自大规模数据（GPT-3 数据集 4990 亿词元）和参数规模（GPT-3 1750 亿参数）。
- 下一词预测是自监督任务，无须人工标签，能利用海量无标注文本。
- 涌现能力让 GPT 能完成未经训练的任务（如翻译）。
- 预训练极其昂贵（GPT-3 460 万美元），但可加载公开权重跳过预训练。
- 本书按"架构→预训练→微调"三阶段路线图展开。
