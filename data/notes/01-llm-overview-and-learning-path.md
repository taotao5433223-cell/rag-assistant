# 01. LLM 全景与学习路径

> 对应章节：前言 + 第 1 章 1.1–1.3

## 一、为什么要从零构建一个大语言模型

作者塞巴斯蒂安·拉施卡在十年前由一门统计模式分类课程入门 AI，2022 年 ChatGPT 的发布让大语言模型（Large Language Model, LLM）风靡全球。他在前言里点出一个反直觉主张：**理解一个 LLM 的最佳方式是从零开始编写一个**。

LLM 看似庞大——参数从数百万到数千亿——但它们并不一定是"黑箱"模型。作者坚信，对基本概念和底层代码的方方面面都建立起信心，是迈向成功的关键。这种信心带来三层下游能力：

1. **修复 bug**：当模型输出异常时，能定位是分词器、嵌入、注意力、训练循环还是权重加载的问题。
2. **优化性能**：能从超参、数据、架构各角度调优，而不只是换 prompt。
3. **产生新想法**：理解了机制，才能改造机制。

## 二、什么是大语言模型

LLM 是一种用于理解、生成和响应类似人类语言文本的神经网络，属于深度神经网络，通过大规模文本数据训练而成，训练资料甚至涵盖互联网上大部分公开文本。

"大语言模型"中的"大"字有两层含义：

- **训练数据庞大**：涵盖数十亿词汇，涉及广泛主题。
- **参数规模庞大**：通常拥有数百亿甚至数千亿个参数（parameter）。这些参数是神经网络中的可调整权重，在训练中不断被优化。

### 2.1 下一词预测任务

LLM 的核心训练任务是 **下一词预测（next-word prediction）**：让模型基于已有文本预测序列中的下一个词。这个任务合理利用了语言本身具有顺序这一特性。看似简单的任务却能孕育出强大能力，许多研究人员对此深感惊讶。

### 2.2 与传统机器学习的区别

- 传统机器学习需要人工特征工程（如手动提取"prize""win""free"等触发词频率）。
- 深度学习不依赖人工特征，但传统深度学习模型仍需标签。
- LLM 的预训练采用 **自监督学习（self-supervised learning）**：模型从输入数据中生成自己的标签——把句子中下一个词当作"标签"，无须人工标注就能利用海量无标注文本。

### 2.3 AI / ML / DL / LLM 的层级关系

```
人工智能 (AI)
└── 机器学习 (ML)
    └── 深度学习 (DL) — 3层及以上神经网络
        └── 大语言模型 (LLM) — Transformer 架构 + 下一词预测任务
```

LLM 通常也被归类为 **生成式人工智能（generative AI / GenAI）**，因为它们能生成文本。

## 三、LLM 的应用领域

LLM 在解析和理解非结构化文本方面能力极强，应用包括：

- 机器翻译
- 文本生成（小说、文章、代码）
- 情感分析
- 文本摘要
- 复杂聊天机器人和虚拟助手（ChatGPT、Gemini 等）
- 医学、法律等领域的文献筛选与知识提取

本书目标是从零开始理解 LLM 工作原理，并实现一个能生成文本的 LLM，再让它能执行回答问题、文本总结、多语言翻译等任务——逐步构建一个像 ChatGPT 这样的复杂助手。

## 四、构建和使用 LLM 的各个阶段

### 4.1 为什么要自己构建 LLM

- 深入了解模型机制和局限性。
- 为预训练和微调开源 LLM 适应特定领域做准备。
- 针对特定领域或任务定制的 LLM 性能往往优于通用 LLM（如金融领域的 BloombergGPT、医学问答模型）。
- **数据隐私**：公司不愿把敏感数据共享给第三方 LLM 供应商。
- **本地部署**：较小定制模型可部署到客户设备（笔记本、手机），降低延迟与服务器成本（苹果等正在探索）。
- **自主权**：完全控制模型更新与修改。

### 4.2 两阶段训练范式

LLM 的构建通常包括 **预训练（pre-training）** 和 **微调（fine-tuning）** 两个阶段：

**预训练**：

- "预"表明它是初始训练阶段。
- 在大规模、多样化的无标注数据集上训练。
- 使用自监督学习（下一词预测）。
- 产出物称为 **基础模型（foundation model）**，如 GPT-3。
- 基础模型能做文本补全，还展现有限的 **少样本学习（few-shot learning）** 能力——基于少量示例学习新任务。

**微调**：

- 在规模较小的特定任务/领域数据集上继续训练。
- 最流行的两种方法：
  - **指令微调（instruction fine-tuning）**：标注数据是"指令-答案"对（如翻译任务的"原文-正确译文"）。
  - **分类微调（classification fine-tuning）**：标注数据是"文本-类别标签"（如"垃圾邮件/非垃圾邮件"）。

```
原始文本（无标注）→ 预训练 → 基础模型 → 微调（指令/分类）→ 任务专用模型
```

## 五、本书的学习路径

本书按 3 个主要阶段逐步实现目标：

1. **第一阶段：实现模型架构和准备数据**
   - 数据预处理基本流程（第 2 章）
   - 实现注意力机制核心组件（第 3 章）
   - 组装 GPT 架构（第 4 章）

2. **第二阶段：预训练大语言模型**
   - 编写预训练代码，得到能生成新文本的类 GPT 模型（第 5 章）
   - 学习评估 LLM 的基础知识
   - 提供加载公开可用模型权重的示例代码

3. **第三阶段：微调基础模型**
   - 文本分类微调（第 6 章，垃圾消息识别）
   - 指令微调（第 7 章，遵循人类指令）

需要指出，从头预训练 LLM 是极其昂贵的（GPT-3 预训练的云计算费用估计 460 万美元；Llama 2 70B 约 69 万美元）。本书出于教学目的使用小数据集，并提供加载公开权重的代码以跳过昂贵预训练。

## 六、关键术语速查

| 术语 | 含义 |
|---|---|
| LLM | 大语言模型，基于 Transformer、以下一词预测为训练任务的深度神经网络 |
| 参数 | 神经网络中的可调整权重，训练中优化 |
| 下一词预测 | LLM 的核心训练任务，利用语言顺序特性 |
| 自监督学习 | 从输入数据自身结构生成标签，无须人工标注 |
| 基础模型 | 预训练后得到的通用模型 |
| 预训练 | 在大规模无标注数据上的初始训练 |
| 微调 | 在带标注的特定任务数据上继续训练 |
| 指令微调 | 用"指令-答案"对微调 |
| 分类微调 | 用"文本-类别标签"对微调 |
| 少样本学习 | 基于少量示例学习新任务 |

## 七、本篇要点

- LLM 不是黑箱，理解它的最短路径是亲手从零实现一个。
- "大"指数据和参数规模，不指"不可解释"。
- 核心训练任务是极简的"下一词预测"，简单任务孕育强能力。
- 两阶段训练范式：预训练（无标注）→ 微调（带标注，分类或指令）。
- 本书按"数据→架构→预训练→微调"三阶段展开，可在笔记本上跑通。
