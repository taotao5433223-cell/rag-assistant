# 05. 注意力机制的诞生：从 RNN 到自注意力

> 对应章节：第 3 章 3.1–3.3

## 一、本章在流水线中的位置

第 3 章聚焦 **第一阶段第 (2) 步：实现注意力机制**——LLM 架构中的关键部分。本章大篇幅单独探讨注意力机制工作原理，编写自注意力机制代码，观察运行过程。

本章实现 4 种注意力变体，每一个都建立在前一个基础上：

```
简化自注意力 → 带可训练权重的自注意力 → 因果注意力 → 多头注意力
```

最终目的是实现紧凑高效的 **多头注意力**，在第 4 章集成到 GPT 架构中。

## 二、长序列建模中的问题

### 2.1 翻译任务的难点

考虑把德语翻译成英语。由于源语言和目标语言语法结构不同，不能简单逐词翻译——翻译需要理解上下文和进行语法对齐。

### 2.2 编码器-解码器 RNN

Transformer 出现前，**循环神经网络（RNN）** 是语言翻译中最流行的编码器-解码器架构。RNN 把前一步骤的输出作为当前步骤的输入，适合序列数据。

工作机制：

1. 编码器读取输入文本，逐步更新隐藏状态（隐藏层内部值）。
2. 编码器把整个输入文本处理成一个 **隐藏状态（记忆单元）**，捕捉输入句子全部含义。
3. 解码器用这个最终隐藏状态开始逐字生成翻译后的句子。

### 2.3 RNN 的关键局限

**编码器-解码器 RNN 的主要限制是：在解码阶段，RNN 无法直接访问编码器中的早期隐藏状态。**

- 它只能依赖当前隐藏状态，该状态包含了所有相关信息。
- 这导致 **上下文丢失**，特别是在复杂句子中，依赖关系可能跨越较长距离。

构建 LLM 不需要深入了解 RNN，但记住 RNN 这个缺陷对注意力机制的设计起到了促进作用。

## 三、注意力机制捕捉数据依赖

### 3.1 Bahdanau 注意力（2014）

2014 年，研究人员为 RNN 开发了 **Bahdanau 注意力机制**（以第一作者命名）。该机制修改了编码器-解码器 RNN，使 **解码器在每个解码步骤中可以选择性地访问输入序列的不同部分**。

核心思想：对于生成某个特定输出词元，某些输入词元比其他输入词元更重要。这种重要性由 **注意力权重** 决定。

### 3.2 Transformer 取代 RNN（2017）

仅仅 3 年后（2017），研究人员发现 RNN 并不是构建 NLP 深度神经网络的必需架构，提出最初的 **Transformer 架构**，其中包含受 Bahdanau 注意力启发的 **自注意力机制**。

### 3.3 自注意力的"自"

在自注意力中，"自"指该机制通过关联 **单个输入序列中的不同位置** 来计算注意力权重的能力。它可以评估并学习输入本身各部分之间的关系和依赖。

这与传统注意力形成对比——传统注意力关注两个不同序列元素之间的关系（如输入序列和输出序列之间）。

### 3.4 自注意力是当代 LLM 的关键组成

自注意力机制是基于 Transformer 架构的当代 LLM（如 GPT 系列）的关键组成部分。第 4 章会编码 LLM 其余部分。

## 四、简化自注意力机制（无可训练权重）

为阐明自注意力中的关键概念，先实现一个 **不包含任何可训练权重的简化版本**。

### 4.1 目标：上下文向量

给定输入序列 x¹, x², ..., x⁶（如 6 个词元，每个是 3 维嵌入向量），目标是 **为每个输入元素 xⁱ 计算一个上下文向量 zⁱ**。

上下文向量是 **包含了序列中所有元素信息的嵌入向量**——通过结合序列中其他所有元素的信息，为每个元素创建丰富表示。

### 4.2 示例输入

考虑输入文本 "Your journey starts with one step."，已嵌入为 3 维向量：

```python
import torch
inputs = torch.tensor(
  [[0.43, 0.15, 0.89], # Your     (x¹)
   [0.55, 0.87, 0.66], # journey  (x²)
   [0.57, 0.85, 0.64], # starts   (x³)
   [0.22, 0.58, 0.33], # with     (x⁴)
   [0.77, 0.25, 0.10], # one      (x⁵)
   [0.05, 0.80, 0.55]] # step     (x⁶)
)
```

### 4.3 步骤 1：计算注意力分数（点积）

以第二个输入 x²（"journey"）作为查询，计算它与其他所有输入的 **注意力分数**。用 **点积** 衡量相似度——点积越大，两元素越相似，关注度越高。

```python
query = inputs[1]  # x²
attn_scores_2 = torch.empty(inputs.shape[0])
for i, x_i in enumerate(inputs):
    attn_scores_2[i] = torch.dot(x_i, query)
# tensor([0.9544, 1.4950, 1.4754, 0.8434, 0.7070, 1.0865])
```

**点积的本质**：将两个向量逐元素相乘后求和。它不仅是把两个向量转化为标量的数学工具，也是度量相似度的方式——点积越大，向量对齐程度越高。

### 4.4 步骤 2：归一化为注意力权重（softmax）

把分数归一化为总和为 1 的 **注意力权重**。简单做法是除以总和，但实际更推荐 **softmax 函数**——它更好地处理极值，并提供更有利的梯度特性。

```python
def softmax_naive(x):
    return torch.exp(x) / torch.exp(x).sum(dim=0)

attn_weights_2 = softmax_naive(attn_scores_2)
# tensor([0.1385, 0.2379, 0.2333, 0.1240, 0.1082, 0.1581])，总和为 1
```

softmax 保证注意力权重为正值（可解释为概率/相对重要性）。注意 `softmax_naive` 在处理极大/极小值时可能有数值稳定性问题（溢出/下溢），实践用 PyTorch 优化版：

```python
attn_weights_2 = torch.softmax(attn_scores_2, dim=0)
```

### 4.5 步骤 3：计算上下文向量（加权和）

把嵌入的输入词元与对应注意力权重相乘，再求和——上下文向量是所有输入向量的加权和：

```python
context_vec_2 = torch.zeros(query.shape)
for i, x_i in enumerate(inputs):
    context_vec_2 += attn_weights_2[i] * x_i
# tensor([0.4419, 0.6515, 0.5683])
```

这个 z² 包含了 x² 及其他所有元素（x¹ 到 x⁶）的信息。

## 五、计算所有输入的注意力权重

### 5.1 矩阵化实现

上述只算了 x² 的上下文向量。推广到所有输入，用矩阵乘法高效实现：

**步骤 1：计算所有注意力分数**

```python
attn_scores = torch.empty(6, 6)
for i, x_i in enumerate(inputs):
    for j, x_j in enumerate(inputs):
        attn_scores[i, j] = torch.dot(x_i, x_j)
# 等价的矩阵乘法：
attn_scores = inputs @ inputs.T
```

**步骤 2：对每行归一化**

```python
attn_weights = torch.softmax(attn_scores, dim=-1)
# dim=-1 表示在最后一个维度（列）上归一化，使每行总和为 1
```

**步骤 3：计算所有上下文向量**

```python
all_context_vecs = attn_weights @ inputs
# 每行一个 3 维上下文向量
```

### 5.2 dim 参数

`torch.softmax(..., dim=-1)`：

- 对二维张量（行, 列），`dim=-1` 等价于 `dim=1`，沿列方向归一化（每行总和为 1）。
- 对三维张量（batch, seq, emb），`dim=-1` 仍沿最后一个维度（嵌入维）操作，避免从 dim=1 转 dim=2 的麻烦。

### 5.3 验证一致性

第 2 行应与之前手算的 `context_vec_2 = [0.4419, 0.6515, 0.5683]` 一致——确实如此。

## 六、点积与相似度的直觉

为什么用点积衡量注意力？因为点积是 **向量对齐程度的度量**：

- 两个向量方向一致 → 点积大 → 相似度高 → 注意力分数高
- 两个向量正交 → 点积为 0 → 无关
- 两个向量方向相反 → 点积负 → 相反

在自注意力中，点积决定了序列中每个元素对其他元素的关注程度。

## 七、简化自注意力的局限

简化版自注意力虽然能计算上下文向量，但 **没有可训练参数**——它只是固定的点积+softmax+加权和。模型无法从数据中学习"应该更关注谁"。

下一节（3.4）会引入 **可训练权重矩阵 Q/K/V**，让模型学会产生"好的"上下文向量——这是真正用于 GPT 的 **缩放点积注意力（scaled dot-product attention）**。

## 八、关键概念速查

| 术语 | 含义 |
|---|---|
| RNN | 循环神经网络，把前一步输出作为当前步输入，适合序列数据 |
| 隐藏状态 | RNN 编码器把整段输入压成的单一向量，是上下文丢失的根因 |
| Bahdanau 注意力 | 2014 年让 RNN 解码器每步可访问输入序列不同部分 |
| 自注意力 | 关联单个输入序列中不同位置计算注意力权重（"自"=同一序列内） |
| 注意力分数 | 查询与每个输入的点积，衡量相似度 |
| 注意力权重 | softmax 归一化后的分数，总和为 1，可解释为相对重要性 |
| 上下文向量 | 所有输入向量按注意力权重的加权和，包含序列全部信息 |
| softmax | 归一化函数，保证输出为正值且总和为 1，处理极值并提供好梯度 |
| dim=-1 | 在张量最后一个维度操作（二维时即列方向） |

## 九、本篇要点

- RNN 把全部输入压进单一隐藏状态，长距离上下文会丢失——这是注意力机制诞生的动机。
- Bahdanau 注意力（2014）让 RNN 解码器每步可选择性访问输入；2017 年 Transformer 证明 RNN 非必需。
- 自注意力中"自"=同一序列内不同位置间计算注意力权重，区别于传统跨序列注意力。
- 简化自注意力三步：点积算分数 → softmax 归一化为权重 → 加权和得上下文向量。
- 点积是相似度度量——点积越大，两元素越相关，关注度越高。
- 矩阵化实现：`attn_scores = inputs @ inputs.T`，`attn_weights = softmax(attn_scores, dim=-1)`，`context = attn_weights @ inputs`。
- 简化版无可训练权重，无法从数据学习——下篇引入 Q/K/V 矩阵，变为缩放点积注意力。
